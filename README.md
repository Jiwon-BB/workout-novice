# 초보 적응 프로그램

웨이트 트레이닝을 처음 시작하는 사람을 위한 주 3일 전신 프로그램 웹앱.
정적 파일만으로 동작하며 서버가 없다. 기록은 브라우저(IndexedDB)에만 저장되고
어디로도 전송되지 않는다.

## 쓰는 법

주소를 열고, 아이폰이라면 공유 → **홈 화면에 추가**를 누르면 앱처럼 실행된다.
한 번 연 뒤에는 오프라인에서도 열린다.

## 구성

| 블록 | 반복 | RIR | 세션 |
|---|---|---|---|
| 적응 1–3주 | 10–15 | 3 | 4종목 10세트, 머신·케이블 중심 |
| 본 블록 4주~ | 8–12 | 2–3 | 7–8종목 17–18세트, 바벨 종목 투입 |

부하는 정해져 있지 않다. 첫 세트에서 직접 입력한 값이 기준이 되고,
이후에는 지난 수행 기록에서 double progression으로 자동 계산된다.

## 근거

처방 파라미터(볼륨 밴드, 반복 구간, RIR 목표, 쉬는시간, 커버리지 룰)는
앱에 포함된 근거 데이터 파일에서 읽는다. 코드에 하드코딩되어 있지 않다.
근거가 없는 항목(워밍업 세트 구성 등)은 화면에 `convention`으로 표시한다.

식이·체지방 감소는 이 근거 데이터가 다루지 않으며 앱은 그에 대해 아무것도 주장하지 않는다.

## 빌드

이 폴더는 생성된 결과물이다. 원본은 별도 저장소에 있고
`python build-artifact.py novice && python build-site.py novice`로 만들어진다.
