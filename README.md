# 트레이닝 프로그램

주 5일 웨이트 트레이닝 웹앱. 정적 파일만으로 동작하며 서버가 없다.
기록은 브라우저(IndexedDB)에만 저장되고 어디로도 전송되지 않는다.

## 쓰는 법

주소를 열고, 아이폰이라면 공유 → **홈 화면에 추가**를 누르면 앱처럼 실행된다.
한 번 연 뒤에는 오프라인에서도 열린다.

## 구성

| 주차 | 목표 볼륨 | 반복 | RIR | 주간 작업 세트 |
|---|---|---|---|---|
| W1 | 33% | 12–15 | 4–5 | 40 |
| W2 | 50% | 10–12 | 3 | 60 |
| W3 | 67% | 8–12 | 2 | 80 |
| W4+ | 100% | 8–12 | 1–2 | 112 |

세션은 Lower A / Upper A / Lower B / Upper B / Day 5(결손 보충) 다섯 가지다.
백스쿼트·오버헤드프레스·바벨로우는 W2부터 들어간다 — 처음 몇 주는 기술 요구가 높은 종목을 피한다.

**시작 부하는 정해져 있지 않다.** 첫 세트에서 직접 입력한 값이 기준이 되고,
이후에는 지난 수행 기록에서 double progression으로 자동 계산된다. 가볍게 시작하는 편이 안전하다.

각 세트는 워밍업과 본세트로 구분되어 표시된다 — 본세트는 채운 배경, 워밍업은 점선 테두리.
워밍업은 볼륨 집계에 들어가지 않는다.

## 근거

처방 파라미터(볼륨 밴드, 반복 구간, RIR 목표, 쉬는시간, 커버리지 룰)는
앱에 포함된 근거 데이터 파일에서 읽는다. 코드에 하드코딩되어 있지 않다.
근거가 없는 항목(워밍업 세트 구성 등)은 화면에 `convention`으로 표시한다.

식이·체지방 감소는 이 근거 데이터가 다루지 않으며 앱은 그에 대해 아무것도 주장하지 않는다.

## 빌드

이 폴더는 생성된 결과물이다. 원본은 별도 저장소에 있고
`python build-artifact.py mirror && python build-site.py mirror`로 만들어진다.
